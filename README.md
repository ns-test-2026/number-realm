# Number Realm

A K–7 math and spelling adventure game. Open it in Safari on an iPad, tap **Share → Add to Home Screen**, then open it once from the icon. After that it works with no internet.

- `index.html`: the whole game
- `sw.js`: saves the game on the device so it runs offline
- `manifest.webmanifest`, `icon-*.png`: the home-screen app name and icon
