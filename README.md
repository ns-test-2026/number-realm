# Number Realm & Number Speedway

Two math games for kids that work offline once installed.

| Game | Address |
|---|---|
| Number Realm | https://ns-test-2026.github.io/number-realm/ |
| Number Speedway | https://ns-test-2026.github.io/number-realm/speedway/ |

**Install on an iPad (on Wi-Fi):** open the address in Safari, tap **Share → Add to Home Screen**, then open the new icon once. After that it works in Airplane Mode.

- `index.html`, `sw.js`, `manifest.webmanifest`, `icon-*.png`: Number Realm
- `speedway/`: Number Speedway (with its own offline cache and icon)
